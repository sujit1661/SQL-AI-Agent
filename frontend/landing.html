The pipeline
Three steps.
Zero SQL required.
  1. 01

    Ask in plain English

    Type your question exactly as you'd say it out loud. "Which products had the most returns last month?" is a perfectly valid query.

    "Show me users who never placed an order"
  2. 02

    Schema-aware SQL generation

    The LLM receives your live schema — real table names, real column types — so it writes valid SQL with no hallucinated column names.

    llama-3.1-8b-instant Groq inference temp=0.1
  3. 03

    Safe execution & results

    Only SELECT queries run against your database. Results render as a table — exportable to CSV in one click.

    SELECT-only guard CSV export live row count
What it handles

Capabilities

Multi-table joins
Handles questions spanning multiple tables without you naming the join condition.
Aggregations & grouping
SUM, COUNT, AVG, GROUP BY — expressed naturally like "total by category".
Date & time reasoning
"Last 30 days", "this quarter", "since January" resolve into correct PostgreSQL date functions.
Live schema sidebar
Every table and column fetched at runtime — always synced with your actual database.
Visible generated SQL
You always see the exact query that ran. No black box — copy, verify, or adapt it yourself.
Read-only safety guard
Backend enforces SELECT-only. No INSERT, UPDATE, or DELETE — even if the LLM tries.
